# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
リモートリポジトリはメンバー共有のリポジトリ
ローカルリポジトリは自分用のリポジトリ

## プッシュとマージの違いは何でしょうか？
プッシュはローカルリポジトリからリモートリポジトリに反映する
マージは作業ブランチの内容をマスターブランチ反映させること

## コミットとプッシュの違い
コミットはローカルリポジトリに行った作業の履歴を残す作業
プッシュはリモートリポジトリへ変更内容を反映させる作業

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
メッセージを見るとどのような変更を行ったかを第三者が見てもわかるように書く。

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
プルリクエストでマージするとリモートリポジトリ上で行われる。　ローカルブランチ上では反映されない。
また、他の人が差分の確認を行いコードレビューをする。

## コンフリクトを起こしてしまった場合、どう対処すべきですか？
３パターン
・先にマージされた変更内容を取り込む
・後にマージしようとしている変更内容を取り込む
・どちらの変更内容も取り込む

いずれにしよ、他の作業者と相談しながら作業を進める必要がある。
